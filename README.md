# Mundo SENAI 2026 — Portfólio

Landing page responsiva para registrar a participação de **João Lucas Morais Braga** no evento Mundo SENAI 2026, com foco em **Sistemas Embarcados, IoT e automação residencial**.

## Como executar

1. Baixe ou extraia todos os arquivos preservando as pastas.
2. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server do VS Code).
3. Para publicar, envie `index.html`, `style.css`, `script.js` e a pasta `assets` ao repositório do GitHub.

## Conteúdo

- Apresentação do projeto e das três maquetes controladas por ESP32.
- Foto da equipe, relato pessoal e feedback do instrutor.
- Botão **O que é o Mundo SENAI?** que abre uma janela de explicação com **OK, entendi!**.
- Design responsivo e sem dependências JavaScript externas.

## Tecnologias

HTML5, CSS3 e JavaScript puro. A tipografia utiliza Google Fonts (fallback local disponível).
